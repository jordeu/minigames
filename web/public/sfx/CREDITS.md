# Recorded sports and impact effects

All five recordings below are licensed CC0 1.0 by their uploaders. Public HQ MP3 previews are bundled locally and decoded into reusable Web Audio buffers. Runtime gain, offsets, fades and occasional playback-rate changes adapt them to game events; the files are otherwise unchanged. No account, network connection or runtime download is required.
