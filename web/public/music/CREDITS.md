# Banana Rooftops background music

**Morning Mood**, from *Peer Gynt Suite No. 1, Op. 46*, by Edvard Grieg.

Performance: Czech National Symphony Orchestra, credited as the Musopen Symphony Orchestra for the Musopen Kickstarter Project (2012).

Recording source and public-domain dedication:
https://commons.wikimedia.org/wiki/File:Musopen_-_Morning.ogg

Original recording information:
https://musopen.org/music/777-peer-gynt-suite-no-1-op-46/

Musopen released this recording into the public domain worldwide, with a fallback grant for any purpose without conditions where that dedication is not legally possible. This applies to the recording, not just the composition. The original Ogg Vorbis file is bundled unchanged for offline use.

File: `morning-mood.ogg`
Duration: approximately 3 minutes 49 seconds.
Source file size: 3,453,888 bytes.
Published SHA-1: `84b855cba2c412c9697895beedfc44d48046931c`

The game loops the complete performance at a reduced playback volume. It pauses and resumes the recording without restarting the piece. No network request is needed during gameplay.
